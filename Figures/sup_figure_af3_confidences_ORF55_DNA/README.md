# Supplementary figure — AlphaFold 3 confidence, ORF55–ATP–DNA co-folding

Self-contained copy of the code and data behind the figure showing that AF3 confidence (ipTM / pTM)
for ORF55 + ATP + **2-nt-gapped** DNA is significantly lower than for intact, nicked or 1-nt-gapped
DNA. Copied from `../revision_2` (was "Fig 1" there).

## Layout

```
├── output/                       the figure + its data (regenerated by scripts/)
│   ├── AF3_confidence_scores.{png,pdf,svg,html}   figure: ipTM (A) and pTM (B), 4 substrates x 25 models
│   ├── AF3_confidence_scores_caption.txt          figure legend + pairwise significance
│   ├── AF3_perModel_results.tsv                   one row per model (100): ipTM, pTM, ranking score
│   └── AF3_summary_confidence.tsv                 mean ± s.d. per substrate
├── scripts/
│   ├── make_supplementary_tsv.py   raw AF3 JSONs -> the two TSVs; prints table + permutation test
│   └── make_supp_figure.py         Plotly figure + caption (needs plotly + kaleido, numpy)
├── af3_results/folds_2026_09_03_19_12/   raw AlphaFold Server output, trimmed to what the scripts read:
│                                         *_summary_confidences_{0-4}.json and *_job_request.json
│                                         for 4 substrates x 5 seeds (orf55_<substrate>_atp_seed<N>)
│                                         + terms_of_use.md
└── inputs/af3_server_jobs/       the AlphaFold Server input JSONs submitted (5 seeds per substrate)
```

Not copied (not needed for this figure): model `.cif` files, `full_data` JSONs, MSAs, templates
(~250 MB in `revision_2/af3_results`), and the accidental `intact_duplex_atp_seed{2,3}_2` re-runs
and the non-ATP `intact_duplex_seed*` runs, which the scripts ignore.

## Reproduce

```
python3 scripts/make_supplementary_tsv.py
python3 scripts/make_supp_figure.py
```

Outputs were verified against the originals in `revision_2/supplementary/` (TSVs and caption are
byte-identical).

## Design

Substrates: ORF55 + ATP with a 21-bp DNA duplex — intact (control), nicked, 1-nt gap, 2-nt gap.
5 AF3 seeds x 5 diffusion samples = 25 models per substrate. Significance: exact permutation test
on per-seed means, 2-nt gap vs each other substrate, P = 0.008 (the minimum possible at n = 5 vs 5).

| substrate | ipTM | pTM |
|---|---|---|
| intact duplex | 0.944 ± 0.005 | 0.947 ± 0.005 |
| nicked | 0.942 ± 0.018 | 0.945 ± 0.009 |
| 1-nt gap | 0.947 ± 0.004 | 0.949 ± 0.003 |
| 2-nt gap | 0.850 ± 0.030 | 0.887 ± 0.030 |
